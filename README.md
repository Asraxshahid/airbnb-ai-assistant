Islamabad Airbnb AI Assistant
A smart virtual assistant designed to enhance Airbnb guest experience in Islamabad.

Features
Chat-based assistant for guests
Instant WiFi & check-in/check-out info
Real-time restaurant suggestions (API powered)
Service requests (towels, cleaning, etc.)
Intent-based response system
Clean chat UI with dark mode

Tech Stack
Python
Streamlit
REST APIs (TomTom)
